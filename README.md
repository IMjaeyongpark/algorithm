# Algorithm

[![Solved.ac Profile](https://mazassumnida.wtf/api/mini/generate_badge?boj=ppjjyy)](https://solved.ac/profile/ppjjyy)

백준과 프로그래머스 문제 풀이를 꾸준히 기록하는 알고리즘 저장소입니다. 자료구조와 알고리즘의 원리를 이해하고, 더 명확하고 효율적인 풀이를 만드는 것을 목표로 합니다.

## 저장소 구성

```text
.
├── 백준/
│   └── 난이도/문제명/풀이
└── 프로그래머스/
    └── 레벨/문제명/풀이
```

- 500개 이상의 문제 풀이를 난이도별로 관리합니다.
- C, C#, Java, Kotlin, Python, SQL을 사용합니다.
- 구현, 자료구조, 그래프 탐색, 동적 계획법, 그리디, 문자열, 데이터베이스 문제를 다룹니다.
- 제출한 정답 코드는 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)를 통해 자동으로 동기화됩니다.

## 풀이 원칙

1. 문제의 입력 범위와 시간 복잡도를 먼저 확인합니다.
2. 풀이에 맞는 자료구조와 알고리즘을 선택합니다.
3. 통과 후에도 가독성과 불필요한 연산을 다시 점검합니다.

> 문제 수와 폴더 구성은 새로운 풀이가 추가되면서 계속 변경됩니다.
